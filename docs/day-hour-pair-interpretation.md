# 六宫日时双宫联断

日时双宫只适用于六宫时间起课：实际结果的中传为日宫、末传为时宫，按“日宫＋时宫”保留顺序查询。30 组传统异宫组合来自 [ProcessOn 资料](https://www.processon.com/view/61de55ce5653bb06cbbc5beb)，另有 6 组同宫现代推导；双宫仅补充解说，不改变三传落宫结果，数字、文字、随机和九宫起课不使用。

问题分类内部 ID 与界面名称为：`lostProperty`—寻物、`travelerMessage`—行人消息、`wealth`—求财、`dispute`—纠纷官事、`relationship`—婚恋合作、`health`—健康。ID 只供程序配置使用，页面统一显示中文；`traditional` 显示传统口诀，`derived` 显示同宫推导。

六宫事项细断按六类现代语义参与初传、中传、末传解说：寻物关注排查路线与线索，行人消息关注联系和行程，求财关注来源与回款条件，纠纷官事关注证据和程序，婚恋合作关注沟通与行动，健康只描述信息和处理节奏。健康内容不用于诊断、疗效或生死判断。

口诀原文与现代解释分开展示。流派方向、时效和危险古断语只作资料说明，不会直接进入自动解说；鬼神、诅咒、死亡等内容会转换为现实中的核实、求助和风险控制建议。
