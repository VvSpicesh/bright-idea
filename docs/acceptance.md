# 首版验收与单体测试

> 状态：早期验收目标。当前实现尚不满足历史记录、JSON 导入导出、查看历史等条目；实际差异见[文档目录](README.md#实现差异)。

## 1. 计算引擎

必须覆盖：

- 六宫和九宫的宫位数组顺序正确。
- 数字 1 落在当前起点。
- 数字等于宫位总数时落在起点前一宫。
- 数字为宫位总数加 1 时回到起点。
- 大整数不通过循环逐次累加，直接使用取模计算。
- 三传分别从大安、初传、中传起数。
- 返回每一步的起点、输入、圈数、余数和落点。

固定样例：

| 体系 | 输入 | 预期三传 |
|---|---|---|
| 六宫 | 1, 1, 1 | 大安、大安、大安 |
| 六宫 | 6, 6, 6 | 空亡、小吉、赤口 |
| 六宫 | 7, 1, 1 | 大安、大安、大安 |
| 九宫 | 1, 12, 6 | 大安、速喜、桃花 |
| 九宫 | 9, 9, 9 | 天德、桃花、病符 |
| 九宫 | 10, 1, 1 | 大安、大安、大安 |

说明：测试编写时必须按通用公式再次人工核对这些预期值；如文档样例与公式冲突，以公式为准并先修正文档，不得为了通过测试修改算法。

## 2. 输入验证

- 三数拒绝 0、负数、小数、科学计数法、空值和非数字。
- 三字按 Unicode 字符处理，不能把扩展区汉字拆开。
- 三字输入忽略首尾及字间空格，但不静默忽略其他内容。
- 非汉字、超过或不足三个汉字时提示明确错误。
- 繁简转换结果和笔画数必须经过确认才能起课。
- 查不到笔画数时必须阻止继续，直到用户手工填写。

## 3. 时间换算

- 十二时辰边界逐个测试。
- 22:59 为亥时，23:00 为子时。
- 跨公历日、跨农历月、跨农历年测试。
- 闰月显示和取数测试。
- 不同设备时区下，保存的时间和显示时间一致。

## 4. 五行关系

- 五种相生关系全部测试正向和反向。
- 五种相克关系全部测试正向和反向。
- 同五行关系测试。
- 六宫与九宫的宫位五行不得串用。

## 5. 历史记录

- 刷新后记录仍存在。
- 旧记录保留规则版本和当时计算结果。
- JSON 导出后可重新导入且字段无损。
- 非法 JSON、未知版本和重复 ID 有明确处理。
- 删除和覆盖导入需要二次确认。

## 6. PWA 与界面

- 360px、390px、430px 手机宽度无横向溢出。
- 键盘弹出后主要按钮仍可操作。
- 支持离线刷新核心页面。
- 深色、浅色模式均有足够对比度。
- 按钮、表单有可访问名称，可仅用键盘完成核心流程。

## 7. 完成标准

- `npm run lint` 通过。
- `npm run typecheck` 通过。
- `npm test -- --run` 通过。
- `npm run build` 通过。
- 无网络时可完成三数起课、三字起课和查看历史。
- 最终报告只列：完成内容、修改文件、测试结果、剩余风险。
